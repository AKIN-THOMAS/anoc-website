# Quick Start Guide - ANOC Multi-Page Website

## What Changed?

Your website is now a **professional multi-page application** instead of a single-page website. Here's what you get:

### ✨ New Features

1. **Separate Pages for Each Section**

   - Home page with hero and stats
   - About Us page with company values
   - Services page with all offerings
   - Team page with member profiles
   - Contact page with locations and form

2. **Professional Navigation**

   - Fixed navbar on every page
   - Active page highlighting
   - Smooth transitions between pages
   - Logo links back to home

3. **Enhanced Design**

   - Modern color scheme with orange accents
   - Professional typography and spacing
   - Smooth animations and hover effects
   - Responsive layouts for all devices

4. **Better User Experience**
   - No page reloads (uses client-side routing)
   - Consistent branding across all pages
   - Professional card layouts
   - Improved visual hierarchy

## Running the Site

```bash
# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Page URLs

- **Home**: `/`
- **About**: `/about`
- **Services**: `/services`
- **Team**: `/team`
- **Contact**: `/contact`

## Navigation

Simply click the menu items in the navbar to navigate between pages. The active page will be highlighted in orange.
